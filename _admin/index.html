Подключение к GitHub

Панель сохраняет изменения прямо в репозиторий. Нужен токен с правом Contents: Read and write.

Как получить токен
  1. github.com/settings/personal-access-tokens/new
  2. Repository access → Only select repositories → havexppf
  3. Permissions → Repository permissions → Contents: Read and write
  4. Generate token и вставьте его ниже

Токен хранится только в этом браузере (localStorage) и не уходит никуда, кроме api.github.com
