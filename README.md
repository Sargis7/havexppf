# HAVEX — сайт PPF бронеплёнок

Премиальный лендинг бренда **HAVEX** (полиуретановые бронеплёнки PPF) с приёмом
заявок, которые уходят напрямую в чат Telegram.

## Быстрый старт

```bash
cd havex-site
npm install
cp .env.example .env     # затем заполните .env
npm start                # → http://localhost:3000
```

Режим разработки с автоперезапуском: `npm run dev`

## Подключение Telegram (обязательно для приёма заявок)

Пока `.env` не заполнен, сайт работает полностью, но форма отвечает
«Приём заявок временно недоступен», а заявка печатается в консоль сервера —
удобно для проверки вёрстки без бота.

### 1. Создайте бота
Напишите [@BotFather](https://t.me/BotFather) → `/newbot` → получите токен вида
`1234567890:AAH...`

### 2. Узнайте chat_id
Напишите своему боту любое сообщение, затем откройте в браузере:

```
https://api.telegram.org/bot<ВАШ_ТОКЕН>/getUpdates
```

Найдите `"chat":{"id":123456789}` — это и есть `TELEGRAM_CHAT_ID`.

Для группы: добавьте бота в группу, напишите туда сообщение и возьмите id
из `getUpdates` (id группы начинается с `-100`).

### 3. Заполните `.env`

```env
TELEGRAM_BOT_TOKEN=1234567890:AAH...
TELEGRAM_CHAT_ID=123456789
PORT=3000
```

Перезапустите сервер. В консоли появится `Telegram: подключён ✓`.

Проверить статус: `GET /api/health` → `{"ok":true,"telegram":true}`

## Соцсети

Ссылки в блоке контактов, футере и плавающая кнопка Telegram в правом нижнем
углу. Замените заглушки `havex` на свои аккаунты:

- Instagram — `https://instagram.com/havex`
- Telegram — `https://t.me/havex`
- YouTube — `https://youtube.com/@havex`

## Что защищено в форме

- валидация на клиенте и на сервере (имя, телефон ≥10 цифр, формат email)
- honeypot-поле `company` — боты получают «успех», но заявка не уходит
- ограничение частоты: 12 заявок на IP за 10 минут
- лимит размера тела запроса 32 КБ
- HTML-экранирование всех полей перед отправкой в Telegram

## Продакшн

Сервер слушает `PORT` и доверяет заголовку `X-Forwarded-For` (для корректного
определения IP за прокси). Запускайте под `pm2`/`systemd` и поставьте перед ним
nginx с HTTPS. Никогда не коммитьте `.env` — он уже в `.gitignore`.
